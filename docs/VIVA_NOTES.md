# Viva notes (plain language)

## Quota pools with release
Each centre-day has a capacity (28 slots × slot capacity). We split it into four pools: TATKAL 20%, Senior+Minor 15%, PCC 10%, and NORMAL gets the rest. An applicant first tries their own pool; if it is empty they may use NORMAL. At 17:00 two days before the appointment day, whatever is still unused in the Senior/Minor and PCC pools is moved into NORMAL so seats are not wasted. TATKAL is never released because TATKAL bookings only open 3 working days ahead. After release, a cancelled seat from those pools goes to NORMAL too.

## Score to verification mode
Each valid document adds 2 if verified or 1 if self-attested. Score 6 or more → POST verification (check after the passport is issued). 3–5 → PRE verification (check before). Below 3 → DOC_BLOCK. A missing or expired mandatory document is DOC_BLOCK regardless of score. RE-ISSUE with no address change skips verification.

## Order of checks
Documents → category → booking window → quota → time preference → earliest slot → fee.
